This page shows sessions and their recordings. With Takeover, this tab controls a session's keyboard and mouse until it releases control, the agent or another viewer takes over, or the lease ends; it cannot connect or disconnect sessions. It can also start and stop recording, annotate and keep recordings. Keep the URL private: anyone with it and network access can view the screens and take control of every session of this daemon. The URL contains the access token, so a reload keeps working.
