<objective>
Add the genuinely new capability of Phase 8: the `WorldStateOptions`/`UiaMode`/`WorldState` public
types and `Session::world_state()` — the first composite/aggregating `Session` method, which sequences
the existing client-side screenshot capture and 0–N sensor round trips under one batch timestamp and
one measured capture span (API-02).

Purpose: SC#2 — a single call returns a correlated, timestamped, serializable snapshot of the remote
desktop combining screenshot + window list + optional UIA, so consumers stop hand-rolling
"fetch three things and hope they're close in time" logic. The a-la-carte options (D-8.1) let a
consumer request only what it needs (keeping structured payloads lean for a downstream agent).
Output: new `worldstate.rs` module, `Session::world_state()`, `lib.rs` re-exports, offline unit tests
using the existing `test_session_with_sensor` mock pattern.
</objective>
