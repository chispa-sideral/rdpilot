<objective>
Write the real UIA handler now that the interop is proven (07-03 gate PASSED): deserialize a `Uia` `{hwnd}` request, walk the direct children via a single `FindAll(TreeScope_Children, trueCondition)` COM call (D-7.4), read the D-7.1 property set per element with a per-element `COMException` skip (D-7.6), and reply with a `{success:true, data:[UiaElementRecord,...]}` envelope matching the wire contract 07-01 locked. Wire it into the Program.cs dispatch loop and register every new DTO for AOT-safe JSON.

This is the mechanical Wave-3 plan — all novel COM risk was retired at the 07-03 gate. It mirrors the Phase 6 `WindowEnumeration.BuildWindowListResponse` handler shape (top-level try/catch degrade + per-element defensive skip) and the `BuildWindowListReplyEnvelope` dispatch/JSON discipline exactly.

Purpose: Produce the SC#1 field-complete `UiaElement[]` payload from real Win32 windows, in the SC#2 physical-pixel coordinate space, using the naive uncached per-property reads D-7.7 mandates first (cache only if the 07-05 live gate shows the 500ms SC#3 budget at risk).
Output: `sensor/UiaTree.cs` (DTOs + handler), Program.cs `MsgType.Uia` arm + `BuildUiaTreeReplyEnvelope`, `Envelope.cs` `MsgType.Uia`, `EnvelopeJsonContext.cs` registrations.

## Trust Boundaries

| Rust SDK → C# sensor (Uia request) | Untrusted `{hwnd}` crosses into ElementFromHandle |
| UIA elements mid-enumeration | Elements can be destroyed between FindAll and property read |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering/DoS | BuildUiaTreeReplyEnvelope / request deserialize | medium | mitigate | Malformed/missing payload → `success:false` (never throws out of the loop); inbound JSON already length-bounded + prefix-scanned in ReadEnvelope (T-05-01). |
| T-07-05 | Information Disclosure | Malicious/foreign hwnd | medium | accept | `ElementFromHandle` on an invalid/foreign handle returns a COM error → top-level catch → `success:false`; UIA enforces the OS's own cross-process element-access boundary (not re-implemented here). |
| T-07-06 | Denial of Service | Per-element property read on a destroyed element | low | mitigate | Per-element `try/catch (COMException) { continue; }` (D-7.6) — one stale element cannot sink the response; top-level catch degrades only on total failure. |
| T-07-03 | Denial of Service | SAFEARRAY decode per element | medium | mitigate | `ReadRuntimeId` (07-02) frees the SAFEARRAY in a `finally` on every element, including the skipped/exception path. |
| T-07-SC | Tampering | Dependency supply chain | low | accept | No new `<PackageReference>` (built-in .NET 8 interop). |
