<objective>
Prove MCP-06 (BLOCKING) offline: a slow tool call in flight does NOT block a concurrent unrelated fast tool call. Add an env-gated slowness hook to the daemon's existing in-process fake test connector (so a genuinely slow daemon round-trip is exercisable without a live RDP target), then drive the MCP handler against the REAL compiled `rdpilot-daemon` binary — mirroring the `rdpilot-daemon/tests/thread_leak_soak.rs` / `rdpilot-cli/tests/cli_lifecycle.rs` "real binary + fake connector" pattern — issuing a slow `rdpilot_put` concurrently with a fast `rdpilot_list`/`rdpilot_world_state` and asserting the fast call returns while the slow one is still pending.

Output: the daemon fake-connector slowness hook; the MCP-06 BLOCKING isolation integration test.
