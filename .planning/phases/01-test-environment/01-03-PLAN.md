Author `infra/scripts/Configure-Target.ps1`: the single idempotent in-guest hardening script the CustomScriptExtension (Plan 02) invokes. It enables WinRM HTTPS, writes 96 DPI and `RemoteDesktop_SuppressWhenMinimized=2` to the correct registry locations (default user hive, not HKCU), and silently installs 7-Zip ONLY after verifying the installer's SHA-256. This is the in-guest half of ENV-01.

Purpose: ENV-01 requires the VM to be reachable over WinRM with `RemoteDesktop_SuppressWhenMinimized=2` set, 96 DPI for the automation user, and 7-Zip installed. The hard parts (RESEARCH.md): per-user settings MUST go to the default user hive because the automation user profile does not exist at provision time (Pitfall 1); the script may re-run on reboot so every mutation MUST be guarded (Pattern 1); the 7-Zip download is a supply-chain risk that MUST be SHA-256-verified (Package Audit). This plan is NOT autonomous: the exact 7-Zip version/URL/SHA-256 must be confirmed at execution time (RESEARCH A3), gated by a blocking human-verify checkpoint.

Output: `infra/scripts/Configure-Target.ps1` — idempotent, no reboot, with a pinned + verified 7-Zip hash.
</objective>
