<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| other Windows account → named pipe | A different local Windows account must be denied by the pipe DACL (DAEMON-02) |
| attacker pre-creating the pipe name → daemon | Pipe squatting must fail creation loudly, not silently attach |
| crashed daemon → live remote Windows session | A possibly-still-live remote session must be surfaced as Orphaned, not forgotten or blindly killed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-01 | Elevation of Privilege | Null/default Windows pipe DACL granting broad access | critical | mitigate | Explicit owner-SID PROTECTED DACL via windows-sys `SetSecurityDescriptorDacl`; live different-account rejection test (Plan 15-05) |
| T-15-02 | Spoofing / Elevation | Named-pipe squatting (attacker pre-creates the pipe) | high | mitigate | `first_pipe_instance(true)` — creation fails loudly; live second-creation-fails test (Plan 15-05) |
| T-15-03 | Repudiation / Destruction of work | Live remote session forgotten or auto-killed on crash-restart | high | mitigate | Live kill-9 + restart test asserts `Orphaned` surfacing + explicit reconciliation (Plan 15-06) |
| T-15-SC | Tampering | New `cfg(windows)` package install | low | accept | `windows-sys` is Microsoft-official and already lockfile-resolved — no `[ASSUMED]`/`[SUS]` package, no legitimacy checkpoint needed (binding direction 3); windows-permissions fallback would re-arm the 12-07 Task-1 checkpoint |
