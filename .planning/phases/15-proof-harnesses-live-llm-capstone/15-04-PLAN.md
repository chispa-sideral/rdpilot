<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local claude CLI → rdpilot-mcp server | The LLM is an autonomous driver issuing tool calls; its tool `input` arguments are effectively external data into the existing FILE-03 path validators |
| remote UI element text → model context | A window title / UIA `name` fed back to the model could attempt prompt injection influencing which path is transferred |
| rendered config temp file → disk | Contains real connection secrets; must be a gitignored temp path, never committed, never logged |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-08 | Information Disclosure | Connection secrets in the rendered `--mcp-config` temp file leaking into logs/trace | high | mitigate | Render to a gitignored temp path; never echo its contents; never print the password; delete after the run |
| T-15-09 | Tampering / Elevation | Prompt injection via a remote UI element's text steering rdpilot_put/get to an unintended path | low | accept | Trusted-operator model (T-14-12); the target is a pre-provisioned, disposable, credential-free VM with no attacker-controlled content in this proof; document in the test's doc comment so a future reuse against untrusted content does not assume hardening |
| T-15-10 | Denial of Service (local) | A malformed claude transcript / hung subprocess stalling the test | medium | mitigate | Bounded subprocess timeout + turn budget; treat missing transcript evidence as an immediate FAIL, never a silent pass |
| T-15-SC | Tampering | package installs | low | accept | No new packages — reuses the rmcp client dev-dep from Plan 15-03; `claude` is a pre-installed local tool, not a crate |
</threat_model>
