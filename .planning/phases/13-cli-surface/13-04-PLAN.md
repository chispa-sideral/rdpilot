<objective>
Wire the daemon's `dispatch.rs` — whose exhaustive match currently routes every operational verb to `not_implemented_for()` — to call the real `rdpilot::Session` methods through `Registry::call` (Plan 13-03), converting the wire DTOs (Plan 13-02) to/from the SDK types. Also close Phase 12's second pre-existing gap: the `Connect` arm never sets `ConnectionConfig::share_root`, so `put`/`get` fail with `Error::Config("...share_root...")` no matter how correct everything else is (research Pitfall 6). Source `share_root` from `rdpilot-config` with a documented default (developer decision #7).

Purpose: This is the layer that makes CLI-02 (perception/input/launch) and CLI-03 (file transfer) actually function end-to-end against the daemon. Without it the CLI would send correct requests and receive `Internal("not implemented")`.
Output: Every operational dispatch arm calls a live session method; `share_root` is wired from config; dispatch tests exercise the new arms against a canned fake session.
</objective>
