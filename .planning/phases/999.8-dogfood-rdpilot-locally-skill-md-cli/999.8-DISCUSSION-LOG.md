## Skill location

| Option | Description | Selected |
|--------|-------------|----------|
| Repo + install to global | Author SKILL.md in-repo at `.claude/skills/rdpilot/SKILL.md` (version-controlled); install step copies/symlinks it to `~/.claude/skills/rdpilot/SKILL.md` for machine-wide discovery | ✓ |
| Global-only | Author SKILL.md directly in `~/.claude/skills/rdpilot/SKILL.md` with no repo copy | |

**User's choice:** Repo + install to global.
**Notes:** Repo is the source of truth; the global copy exists purely as the discovery surface for other agents on this machine. User explicitly asked for an additional `~/.agents/` mirror of the same SKILL.md so non-Claude agents on this box can also discover the rdpilot CLI — the install step now targets BOTH `~/.claude/skills/rdpilot/SKILL.md` and `~/.agents/`.

## Install scope

| Option | Description | Selected |
|--------|-------------|----------|
| Script: CLI + daemon + config skeleton | Repeatable install script/justfile target builds and installs both `rdpilot` and `rdpilot-daemon` binaries to `~/.cargo/bin`, seeds a gitignored `~/.config/rdpilot/config.toml` skeleton, and installs SKILL.md to the global skills dir | ✓ |
| CLI-only (`cargo install --path crates/rdpilot-cli`) | Rely on the existing single-crate install path | |

**User's choice:** Script: CLI + daemon + config skeleton.
**Notes:** The daemon must be on PATH because the CLI auto-starts it via `connect_or_spawn`; CLI-only install is insufficient for a working dogfood setup.

## Session naming for shared use

| Option | Description | Selected |
|--------|-------------|----------|
| Self-owned session name + pre-connect collision check | Each agent uses a stable, self-owned session name convention (e.g. `<agent>-<purpose>`), runs `rdpilot list` BEFORE connecting to check for collisions, and treats the session name as ownership | ✓ |
| Shared well-known session / default target | Agents share a single well-known session name or rely on a default target | |

**User's choice:** Self-owned session name + pre-connect collision check.
**Notes:** No shared well-known session and no reliance on a default — consistent with D-18: explicit session identity, no default target.

## Daemon lifecycle etiquette

| Option | Description | Selected |
|--------|-------------|----------|
| Agents disconnect explicitly; auto-start/idle-reap is backstop only | Skill tells agents not to manage the daemon directly (auto-start on first connect handles startup); agents MUST `disconnect` their session when finished; idle-reap + self-shutdown-on-empty are safety-net backstops, not the primary cleanup path | ✓ |
| Rely on idle-reap/self-shutdown as primary cleanup | Agents leave sessions open and let the daemon's idle-reap and empty-registry self-shutdown handle cleanup | |

**User's choice:** Agents disconnect explicitly; auto-start/idle-reap is backstop only.
**Notes:** Keeps live sessions and in-daemon credentials from lingering.

## Install smoke test

| Option | Description | Selected |
|--------|-------------|----------|
| `--version` + `list` smoke test | Install script runs `rdpilot --version` and `rdpilot list` (the latter auto-starts the daemon and confirms the IPC socket path end-to-end), then prints config path and next-steps | ✓ |
| No self-verification | Install script only builds/copies binaries with no post-install check | |

**User's choice:** `--version` + `list` smoke test.
**Notes:** Confirms the CLI→daemon path is functional before relying on it.
