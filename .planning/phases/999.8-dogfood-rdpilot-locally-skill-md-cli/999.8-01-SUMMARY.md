## Deviations from Plan

**1. [Rule 2 - Missing critical functionality] Added explicit `PATH` export in install-local.sh**
- **Found during:** Task 2/3 boundary (discovered while preparing to execute the script — a fresh non-login Bash session on this box did not have `~/.cargo/bin` on `PATH` by default, unlike an interactive login shell which sources `~/.cargo/env` via `.bashrc`)
- **Issue:** Without this, the script's own D-8 smoke test step (`rdpilot --version` / `rdpilot list`) could fail with "command not found" depending on how/where the script is invoked, even though the binaries were installed correctly by the preceding step in the SAME script run
- **Fix:** Added `export PATH="$CARGO_ROOT/bin:$PATH"` near the top of the script, after variable definitions, before any command that needs `rdpilot`/`cargo`/`rustc` resolution
- **Files modified:** `scripts/install-local.sh`
- **Verification:** Ran the full installer twice (fresh install + idempotency re-run) from a shell that did NOT have `~/.cargo/bin` pre-exported in its own environment variable (only exported for the outer verification commands); the script's internal `export PATH=...` line made its own smoke test succeed regardless
- **Committed in:** `aa15adb` (part of Task 2 commit — this was folded into the initial authoring, not a separate fix-up commit, since it was caught before the file was first committed)
