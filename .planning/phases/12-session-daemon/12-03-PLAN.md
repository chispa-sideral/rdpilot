    `async fn open(&self, name: Option<String>, host: String, cfg: ConnectionConfig) -> Result<SessionId, DaemonError>` implementing Pattern 1 EXACTLY: resolve the id (caller-supplied name → `SessionId::from_str`; `None` → `generate_auto_id()`); in a scoped block, lock the mutex, `match guard.entry(id)` — `Occupied => return Err(DuplicateSession)`, `Vacant => insert SessionEntry::Connecting { claimed_at: Instant::now() }`; END the block (drop the guard) BEFORE any `.await`. CRITICAL: never let a removed `Live` entry drop without `close().await` (this is the DAEMON-01 failure mode). Grep-checkable: every `.remove(` is followed by a matching `.close().await` on the `Live` arm.
    `fn list(&self) -> Vec<SessionStatus>` — lock, map each `(id, entry)` to a `SessionStatus` via the seam's render method (Plan 02), drop the guard, return. Credential-free by construction (SessionEntry holds no password).
