## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| other Windows account → named pipe | A different local Windows account must be denied by the pipe DACL (DAEMON-02) |
| attacker pre-creating the pipe name → daemon | Pipe squatting must fail the daemon's creation loudly, not silently attach |
| crashed daemon → live remote Windows session | A possibly-still-live remote session must be surfaced, not forgotten or blindly killed |
