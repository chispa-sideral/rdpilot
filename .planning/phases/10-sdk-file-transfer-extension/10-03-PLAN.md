| Boundary | Description |

| Rust SDK → C# sensor (DVC command) | The FileTransfer request payload (remote_path, share_name, op) is untrusted input to the sensor; validated before any System.IO call |
| C# sensor → remote Windows filesystem | The validated real remote path is where the sensor reads/writes actual remote-machine bytes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-02 | Tampering / Elevation | FileTransfer.cs ValidateRemotePath | critical | mitigate | Path.GetRelativePath + `..`-prefix/rooted rejection (NEVER StartsWith) under the remote share root; unconditional separator normalization first; FILE-03 C# selftest (Task 3) — Pitfall 3, D-10.2 |
| T-10-05 | Tampering (integrity) | FileTransfer.cs copy loop | high | mitigate | Inline SHA-256 (IncrementalHash) computed in the same pass as the copy, returned for cross-side verification (D-10.5) |
| T-10-06 | Denial of Service | FileTransfer.cs FileStream loop | medium | mitigate | Bounded 64KiB buffer streamed loop; never load the whole file into memory (mirrors the Rust bounded-IO discipline) |
| T-10-SC | Tampering | C# dependencies | low | accept | No new NuGet — BCL `System.Security.Cryptography.SHA256` only, confirmed NativeAOT-safe (D-10.5, 10-RESEARCH Assumption A2) |
