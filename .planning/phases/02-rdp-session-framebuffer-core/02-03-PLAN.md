<objective>
Prove the phase works end-to-end against the live Phase 1 target. Add the example binary
that composes the public API (load `.secrets/connection.json` → `Session::connect` → `screenshot` →
write PNG), the gated integration suite covering all 5 success criteria, and the shared test helper
that loads the connection config and SKIPS when no target is present so the default `cargo test`
never hard-fails (D-18). Finish with a blocking human-verify checkpoint that runs the canonical
validation (`RDPILOT_LIVE=1 ... --include-ignored`, full 10-min idle) against a freshly provisioned VM.

Purpose: Criteria #1 (connect/auth), #2 (RGB-correct screenshot), #3 (crop-to-rect), #4
(stays-rendered windowless/idle), and #5 (10-min keepalive) are only meaningfully provable against a
real Windows RDP target — this plan is the Nyquist phase-gate. Crop math already has offline unit
coverage from Plan 01; here it gets a live end-to-end assertion too. The known-pixel RGB assertion is
the criterion-#2 acceptance check (guards against the YUV-grey pitfall).

Output: a runnable `examples/screenshot.rs`, a `tests/live_session.rs` suite (gated), a reusable
`tests/common/mod.rs` loader, and a recorded canonical-run pass that gates `/gsd-verify-work`.
</objective>
