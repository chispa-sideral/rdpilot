|----------|-------------|
| caller → ConnectionConfig | Untrusted/operator-supplied host, port, credentials, dimensions enter the SDK here |
| caller → Screenshot::crop(Rect) | Caller-supplied Rect crosses into buffer-index math |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Denial of Service | `Screenshot::crop` index math on a malformed/oversize `Rect` | mitigate | Bounds-check the Rect against width/height; return `Err(Error)` on out-of-bounds, never `unwrap`/`panic` (API-01); covered by an explicit out-of-bounds unit test |
| T-02-02 | Information Disclosure | Credentials in `ConnectionConfig` leaking via `Debug`/logs | mitigate | Custom/redacted `Debug` so the password field never prints; never `tracing`-log credential fields; library is env-agnostic, no secrets path hard-coded (D-12) |
| T-02-03 | Spoofing/Tampering | `accept_invalid_certs` flag (consumed in Plan 02, defined here) | mitigate | Flag is risk-named, default `false`; documented lab-only; thumbprint pinning deferred (D-15) — full MITM mitigation enforced at the connect path in Plan 02 |
