## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SDK request → launch handler | `exe`/`args`/`cwd` are caller-controlled and drive an intentional remote-code-execution primitive inside the authenticated RDP session |
| remote processes → sensor | Process names/paths are untrusted strings from arbitrary processes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-03 | Elevation of Privilege | LaunchProcess handler | medium | accept | Arbitrary process launch is PROC-01's intended capability; the RDP session's NLA/CredSSP is the sole/sufficient trust boundary (RESEARCH Security Domain V4) — accepted-by-design, no new gate |
| T-06-04 | Denial of Service | CreateProcessW / OpenProcess handles | medium | mitigate | Always CloseHandle both hProcess+hThread immediately after reading the PID, and the Toolhelp32 snapshot + every OpenProcess handle in a finally (Pitfall 6) — no handle-table exhaustion across a long-lived sensor session |
| T-06-07 | Tampering | WMI/System.Management temptation | high | mitigate | Toolhelp32 P/Invoke only; a build-time grep gate asserts no `System.Management`/`ManagementObjectSearcher` reaches the sensor (dotnet/runtime#61960 — InvalidProgramException under trimming) |
| T-06-01 | Tampering/DoS | all three handlers / request deserialize | medium | mitigate | try/catch → success:false; `envelope.Payload?.Deserialize` returns null/throws-caught on malformed payload → dropped, never crashes the loop (T-05-01, ASVS V5) |
| T-06-SC | Tampering | dependency supply chain | low | accept | No new `<PackageReference>` (kernel32/user32 via LibraryImport) — RESEARCH Package Legitimacy Audit: N/A |
